# Project Overview

## Project Name

Lions United Sports Website

## Project Type

Professional sports organization / sports academy website.

## Reference Website

https://lionsunitedsports.com/home

The live reference website is the primary visual reference for this project.

The objective is to create a complete website that captures the reference website's:

- Visual identity
- Layout system
- Typography hierarchy
- Color relationships
- Navigation structure
- Content hierarchy
- Image treatment
- Component patterns
- Responsive behavior
- Interaction patterns
- Overall user experience

The implementation must be original, maintainable, reusable, and production-ready.

---

# Design Objective

The website should feel:

- Professional
- Athletic
- Energetic
- Premium
- Trustworthy
- Modern
- Community-oriented
- Visually strong

The website must not look like a generic AI-generated sports template.

Avoid unnecessary:

- Glassmorphism
- Excessive gradients
- Random animations
- Excessive rounded cards
- Decorative UI without purpose
- Generic SaaS patterns
- Unrelated visual styles

---

# Primary Users

The website is intended for people interested in the sports organization, including:

- Players
- Parents
- Students
- Athletes
- Coaches
- Sports enthusiasts
- Event participants
- Visitors looking for sports programs
- People looking to contact or join the organization

---

# Primary User Goals

Visitors should be able to quickly:

1. Understand what Lions United Sports offers.
2. Discover sports/programs.
3. Learn about the organization.
4. Explore events and activities.
5. View sports imagery.
6. Learn how to participate.
7. Contact the organization.
8. Navigate the website easily on any device.

---

# Design-First Workflow

This project follows:

Reference Website
        ↓
Impeccable
        ↓
Design System
        ↓
Claude Code
        ↓
Production Website

Impeccable is responsible for establishing and refining the visual direction.

Claude is responsible for implementing the approved design.

Claude must not independently redesign the website during implementation.

---

# Reference Analysis Principle

The reference website must be studied visually.

Do not rely only on extracted text.

Analyze:

- Header
- Navigation
- Hero
- Sections
- Cards
- Images
- Typography
- Colors
- CTAs
- Forms
- Footer
- Mobile navigation
- Responsive layouts
- Interactions
- Animations

When the reference is ambiguous, make the closest professional interpretation while preserving the overall design language.

---

# Content Principle

Content should be realistic and sports-focused.

Do not use lorem ipsum.

Do not create excessive marketing copy.

Content should be:

- Concise
- Clear
- Energetic
- Professional
- Easy to scan

---

# Implementation Principle

Build a reusable design system.

Repeated UI must be implemented through reusable components.

Do not duplicate components simply because they appear on different pages.

---

# Technical Direction

Preferred implementation:

- Next.js
- React
- TypeScript
- Tailwind CSS
- App Router

Use strict TypeScript.

Never use `any`.

Use semantic HTML and accessible components.

---

# Source of Truth Priority

When there is a conflict, follow this order:

1. Explicit project requirements
2. Approved Impeccable design
3. Reference website
4. Existing project design tokens
5. General implementation conventions

Do not override an explicit project requirement based on personal preference.
