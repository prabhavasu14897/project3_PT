# Frontend Experience Skill

## Purpose

Build polished, production-quality frontend experiences for the Lions United Sports website.

This skill focuses on:

- Visual quality
- UX
- Responsive layouts
- Content presentation
- Conversion
- Accessibility
- Performance

---

# Visual Priority

Prioritize in this order:

1. Visual hierarchy
2. Content clarity
3. Brand consistency
4. Usability
5. Responsive behavior
6. Accessibility
7. Performance

---

# Sports Website Patterns

Use patterns appropriate for sports organizations:

- Hero storytelling
- Sports/program cards
- Event cards
- Team profiles
- Statistics
- Image galleries
- Testimonials
- Calls to action
- Registration/enquiry forms
- News/content cards

Do not automatically use ecommerce patterns such as:

- Product grids
- Shopping carts
- Product filters
- Pricing tables

unless explicitly required.

---

# Hero

Hero sections should have:

- Strong imagery
- Strong headline
- Supporting message
- Clear CTA
- Appropriate contrast

Avoid overcrowding the hero.

---

# Content Sections

Every section must have a clear purpose.

Prefer:

Heading
Supporting text
Primary content
CTA

when appropriate.

Avoid sections that exist only for visual decoration.

---

# Cards

Use cards for structured content.

Cards should have:

- Clear hierarchy
- Consistent image ratio
- Consistent spacing
- Predictable interaction
- Appropriate hover state

---

# Calls To Action

Every major page should have a logical next action.

Examples:

- Learn More
- Explore Programs
- View Events
- Join Us
- Contact Us

CTA wording must match the actual user intent.

---

# Responsive Design

Mobile layouts must be intentionally designed.

Adapt:

- Navigation
- Hero
- Cards
- Grid
- Typography
- Images
- CTA
- Footer

Do not simply reduce widths.

---

# Accessibility

All interactions must support:

- Keyboard
- Focus
- Screen readers
- Touch
- Appropriate contrast

---

# Performance

Images are especially important.

Use optimized images and appropriate responsive sizing.

Avoid loading unnecessarily large images on mobile.

---

# Quality Standard

The result should look like a professional agency-built sports website, not an AI-generated template.
